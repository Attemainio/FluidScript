# Future work is evidence-gated

This directory records post-v1 possibilities, not promised features or an implementation backlog.
[`72-roadmap.md`](72-roadmap.md) is the scope authority: each candidate names the evidence or consumer
that would justify promotion. [`71-export-formats.md`](71-export-formats.md) applies that gate to
interchange formats.

When a candidate is promoted, a binding `D-` entry records the decision and rationale, the roadmap row
is struck through with that citation, and milestone and owning contract documents are updated together.
Unpromoted rows must not be implemented merely because they appear here.
