# spacing

How far apart components are drawn.

```fluidscript
fluidscript 1
spacing 20
```

A drawing setting and nothing else: it changes the diagram, never the model. The number is in the
diagram's own units, so it takes no unit symbol — `spacing 20 mm` is an error rather than a
conversion.
