## Verified clean, stated explicitly

- **No second C-76.** `EquationSystem` is built fresh per solve and evaluated on one thread; `SolveContext` is a `readonly ref struct`, so a component cannot cache a solver buffer across iterates; every `EvaluateResiduals`/`TryEvaluateAt`/Jacobian path is allocation-free as documented; `DenseLu`'s stackalloc-or-heap switch is guarded. No `IDisposable`, streams or pools anywhere in Core; the only native state is the (fixed) backend.
- **C-76's fix reviewed:** `[ThreadStatic]` is safe because no `await` sits between `Update` and `Read`; a rejected `Update` cannot be read stale because every entry updates before it reads; the catch-alls are the documented no-throw boundary at the one native seam.
- **Numerics:** every scale a residual or Jacobian divides by is floored positive; `DenseLu.Factor` uses a norm-relative singularity floor; `BranchResistance.Across` bounds its inner Newton at 20 steps and checks `IsFinite`; every sizer checks density/flow before dividing and declines rather than emits NaN.
- **Termination:** `Decompose`'s `while (true)` marks a fresh port slot per step and terminates in ≤ 2×ports; `Equipotential` is a monotone fixed point; union-find strictly decreases; the lexer advances `_position` on every branch including the `Unknown` fallback; `SplitLines` guarantees non-empty token arrays. No recursion in Topology or Sizing.
- **Cycle basis** correct on self-loops and multi-edges (hand-traced).
- **Statics:** `ComponentRegistry.Default`, unit tables, role registries, `Dimension.Entries` are build-once immutable; `Binder.Bind` makes a fresh `BindingRun` per call.
- **Quantity arithmetic** honours the Temperature/TemperatureDelta invariant in every `Try*` path.
- **Security:** no endpoints, SQL, secrets, crypto, regex-over-input or file handling in Core. Not a dependency/CVE scan.
